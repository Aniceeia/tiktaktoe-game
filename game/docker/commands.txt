пример curl-запроса
curl -X POST http://localhost:8080/register \
  -H "Content-Type: application/json" \
  -d '{"login":"alice", "password":"alicepass"}'

включить докер:
docker-compose up --build

отключить докер:
docker-compose down -v --remove-orphans

удалить все образы:
docker rmi $(docker images -q)
