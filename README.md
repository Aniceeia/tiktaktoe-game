## Крестики-нолики

1. Запустите приложение:
   ```bash
   go run cmd/main.go
   ```

2. В консоли создайте игру:
   ```
   curl -X POST http://localhost:8080/games
   ```

3. Сделайте ход через веб, используя ID из консоли:
   ```bash
   curl -X POST -H "Content-Type: application/json" -d '{"board":[[1,0,0],[0,0,0],[0,0,0]]}' http://localhost:8080/games/\game_id
   ```

 1 - вы, 2 - минимакс.
 Теперь вы увидите ответ с обновленной доской. 
 
 В следующем ходе не забудьте указать ход компьютера(дописать 2-ку вместо нуля), иначе ваш ход будет считываться как неверный!

 Примечание:
 Игра работает только через curl.
